# EvoSkills-inspired strategy port
This is a compact original port, not execution of EvoSkills' scripts or Elo system.
Organize supplied papers as challenges linked to possible insights. Start from several
fundamentally different mechanisms. Examine each as an innovator (new angle), pragmatist
(executable experiment), and critic (what knowledge would be gained). Revise within the
mechanism if coherent; pivot when the central assumption is untenable. Simplify without
removing what is genuinely new. Do not equate missing links in a small literature map
with globally unsolved problems. Return the strongest distinct routes, each with a
minimal test, evidence limits and explicit risks. No fictional role transcripts or scores.
