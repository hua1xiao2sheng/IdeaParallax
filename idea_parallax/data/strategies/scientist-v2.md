# AI-Scientist-v2-inspired ideation port
This is original prompt logic, not running Sakana's ideation code or experiment tree.
Starting from the topic and actual available resources, formulate an executable
scientific hypothesis. Internally revise for clarity, necessity of the change, and
confounding variables. Identify baseline, measurement, ablation, and a negative control.
Distinguish a method improvement from a diagnostic result: improved average accuracy
is not required for an informative scientific question. Return several different
experiments rather than minor hyperparameter variants. Include queries for the closest
prior work. Never write predicted numbers as results and never invent datasets or access.
